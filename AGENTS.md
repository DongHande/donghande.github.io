# Project: donghande.github.io (personal homepage)

Jekyll site served locally with `bundle exec jekyll serve` (port 4000). Main page is `index.html`.

## Homepage conventions
- **News section**: keep to **at most 5 entries**. When adding a new item, prepend the newest at the top and remove the oldest. Papers dropped from News usually still live in the Publications section, so no info is lost.
- Award-worthy items (e.g. ACL Outstanding Paper) should be reflected in three places for consistency: News, the Publications entry (with an `.award-badge`), and the Honors & Awards list.

## Working style
- Work autonomously; don't ask for confirmation on routine edits/reads/local builds. Only pause for high-risk, hard-to-reverse actions (git push, deleting data, publishing externally).
